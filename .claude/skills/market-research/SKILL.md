# Market research

## Inputs
- clients/<client>/brief/brief.md
- clients/<client>/context/*.md

## Steps
1. Read the brief and context. List 5 research questions this campaign needs answered.
2. Search the web for each question. Prefer: Vietnamese forums and reviews,
   TikTok/YouTube comment themes, Shopee/TikTok Shop listings, industry reports.
3. Write clients/<client>/research/market-research.md with these sections:
   - Summary (5 bullets)
   - Audience segments (3): who, situation, what they want, what they fear
   - Pain points: quote or paraphrase real customer language, with source link
   - Competitor landscape: what 4-6 competitors claim, what nobody says (white space).
     Competitor names stay in this file only.
   - Trending formats: 3-5 content formats working in this category now, with example links
   - Opportunities: 3 angles this brand can own
   - Sources: numbered list of every link used
4. Return a 5-line summary to the CEO.

## Quality check
- Every factual claim has a source link
- No invented statistics
- Pain points sound like real people, not marketing copy

## Never
- Generate media
- Put competitor names in creative recommendations
