# File naming

<client>-<type><nn>-<placement>-<ratio>.<ext>

type:  S = static image, V = video, SH = short, REF = product reference
placement: feed, story, reel, hero
ratio: 1x1, 4x5, 9x16, 16x9

Examples:
thalo-S01-feed-4x5.png
thalo-S04-story-9x16.png
thalo-V01-reel-9x16.mp4
thalo-SH01-reel-9x16.mp4
thalo-REF01-hero-1x1.png

Never overwrite a kept file. A new version gets a suffix: -v2, -v3.
