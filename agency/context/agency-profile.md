# Agency profile

We are a small AI-run marketing agency for new consumer brands in Vietnam.
We sell one main package:

## Launch Package (2 weeks)
- Market research (audience, pain points, competitors, trends)
- Campaign concept (big idea, 3 angles, visual style)
- 6 static ads: 3 feed 4:5 + 3 story 9:16
- 3 short video ads: 9:16, 8–15 s, hook in the first second
- 1 short-form edit with on-screen text (9:16)
- Captions in Vietnamese for every asset + 2 hook variations per video
- 14-day posting calendar (TikTok, Instagram, Facebook)
- Client report (PPTX)

## How we work
- The human owner approves strategy and the first test shot before money is spent.
- Every claim in research has a source link.
- Every file is saved in the client's folder with the agreed file name.
